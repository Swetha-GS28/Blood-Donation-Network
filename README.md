# Blood Donation Network

## About the Project

Blood Donation Network is a web-based platform that helps connect blood donors with people who need blood during emergency situations.

The system allows users to register as donors, search for suitable donors, submit emergency blood requests, and create matches between donors and emergency requests.

## Technologies Used

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- MySQL
- REST API

## Main Features

- Donor registration
- Donor search by blood group and location
- Emergency blood request
- Matching donors with emergency requests
- Match history
- User registration and login
- Dashboard statistics
